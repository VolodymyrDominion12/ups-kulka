# Вибір VPS для «УПС! Кулька» — дослідження провайдерів

Статус: дослідження, рішення ще не прийняте (відкрите питання з
[технічного плану](<УПС! Кулька — технічний план реалізації магазину.md>)
і [`specs/012-deploy`](../specs/012-deploy/spec.md)). Ціни перевірені на
сторінках провайдерів **06.11.2026**, курс НБУ: 1 € = 51,04 ₴, 1 $ = 45,44 ₴.
Ціни змінюються — перед оплатою перевірте на сайті.

## 1. Скільки ресурсів реально треба

Продакшн-стек (`deploy/compose.prod.yml`) — це 5 контейнерів: Caddy, Next.js
(`web`), FastAPI (`api`), PostgreSQL 17 (`db`), `backup`. Образи збираються в
GitHub Actions, **на сервері нічого не збирається** — тому CPU потрібен лише
на роботу сайту.

| Контейнер | RAM, орієнтовно | Пік |
| --- | --- | --- |
| caddy | 30–60 МБ | 100 МБ |
| web (Next.js standalone) | 150–250 МБ | ~400 МБ під навантаженням |
| api (uvicorn + Pillow) | 120–200 МБ | 400–600 МБ під час обробки фото 15 МБ → WebP/AVIF ×4 |
| db (Postgres 17, до 60 товарів) | 80–150 МБ | 300 МБ під час бекапу |
| backup (pg_dump + tar) | 20–40 МБ | 150 МБ раз на добу |
| Docker + Ubuntu | 250–400 МБ | — |
| **Разом** | **≈0,9–1,2 ГБ** | **≈1,5–2 ГБ** |

Це оцінки за типовим споживанням такого стеку (виміряти точно можна лише на
сервері: `docker stats --no-stream` після першого деплою).

Звідси вимоги:

- **4 ГБ RAM — мінімум для проєкту.** Причина не в середньому споживанні, а в
  трьох піках: завантаження фото з телефона (Pillow тримає в пам'яті
  розпаковане зображення + генерує 8 варіантів), `docker compose pull`
  (розпакування образів) і одночасний запуск **staging + production на одному
  VPS** (план у `specs/012-deploy`): це подвоює `web/api/db`.
- **2 ГБ** вистачить хіба що на production без staging і без одночасних
  завантажень фото — це режим «на межі», не для магазину, який приймає
  замовлення. Якщо все ж брати 2 ГБ, то `STAGING_ENABLED` не вмикати, а на
  сервері зробити swap 2 ГБ.
- **2 vCPU** достатньо: Next.js SSR + API на такому трафіку не впираються в
  CPU. 1 vCPU брати не варто — завантаження й обробка фото серіалізуються.
- **Диск 40 ГБ** достатньо: образи ≈1,2 ГБ, `pgdata` — одиниці ГБ, фото
  каталогу — одиниці ГБ, бекапи за 14 днів — сотні МБ. 50–80 ГБ у тарифах
  українських провайдерів — приємний бонус, не вимога.
- **Трафік:** 5 ТБ на місяць — з великим запасом (уся вага сайту — фото).
- **Обов'язково:** KVM (не OpenVZ/LXC — інакше Docker поводиться непередбачувано),
  root, IPv4 включений, Ubuntu 24.04.

## 4. Висновки

1. **Україна зараз дорожча за ЄС у 2–3 рази** за ті самі 2 vCPU / 4 ГБ:
   550–1 077 ₴ (€11–21) проти €3,8–6,5. Дешевші за європейські лише окремі
   акції та довгі передоплати.
2. **Найдешевше з перевіреного — OVHcloud VPS-1 (≈€4/міс, ~204 ₴)** і
   **AlphaVPS C4G (€3,99)**. OVH кращий як «основний» варіант: великий
   провайдер, Tier-III ДЦ, ДЦ у Варшаві (найближчий до Києва), безлімітний
   трафік, щоденний бекап у ціні, 0 % ПДВ для українського покупця.
3. **Hetzner CX23 (€5,99)** — найкращий досвід і 20 ТБ трафіку, але лінійка
   Cost-Optimized періодично розпродана; якщо в наявності — брати її.
4. **Якщо сервер принципово має бути в Україні:** мінімум — SVAI (550 ₴,
   уточнити ДЦ і трафік), розумний компроміс — Ukrnames (706 ₴, власний ДЦ,
   Харків) або Ukraine.com.ua (957 ₴ за 6 ГБ), максимум надійності —
   HOSTiQ/VPS.ua (1 014 ₴, Львів, генератори, повернення коштів 30 днів).
5. **Латентність** не вирішальна: Київ → Варшава ≈20–25 мс, → Франкфурт/
   Нюрнберг ≈30–40 мс, український ДЦ ≈5–15 мс. Сторінки рендеряться на
   сервері й кешуються, тож різниця в TTFB — десятки мілісекунд. За
   потреби додається CDN (Cloudflare), це окрема задача.

### Рекомендація

- **Ціна + надійність:** OVHcloud VPS-1 у Варшаві (2 vCPU / 4 ГБ / 40 ГБ NVMe,
  безлімітний трафік, щоденний бекап) — ≈€4/міс ≈ 200 ₴/міс. Запасний
  варіант — Hetzner CX23, якщо є в наявності.
- **Принципово Україна:** Ukrnames VM3-KVM (706 ₴, Харків) або
  Ukraine.com.ua NVMe VPS 6G (957 ₴, Київ, 6 ГБ).
- **Не брати 2 ГБ** і не брати 1 vCPU: проєкт із фото-конвеєром і staging на
  тому ж сервері впирається в пам'ять, а не в диск.

## 5. Що перевірити перед оплатою

- [ ] KVM (не OpenVZ), root, **IPv4 включений** у ціну (а не «+€2»).
- [ ] Ubuntu 24.04 доступна як образ.
- [ ] Ціна **продовження**, а не тільки першого місяця/промо.
- [ ] ПДВ: для України в Hetzner/OVH/AlphaVPS — 0 % (експорт); Contabo
      нарахує 20 %. Для ТОВ український постачальник дає податкову накладну з
      ПДВ (20 %) — це може змінити вибір на користь UA.
- [ ] Спосіб оплати: картка українського банку (усі перелічені приймають,
      OVH/Hetzner інколи просять документи для верифікації).
- [ ] Бекапи: чи є снепшот/бекап у тарифі; локальний бекап із
      `deploy/backup.sh` — це той самий диск, копія назовні обов'язкова.
- [ ] Політика повернення (HOSTiQ/VPS.ua — 30 днів, AlphaVPS/OVH — за
      умовами).
- [ ] Чи не блокує провайдер пошту/22-й порт і чи є DDoS-захист.

## 7. Ризики

- **Hetzner Cost-Optimized розпроданий** — не планувати деплой «на завтра» на
  CX23, мати запасний варіант.
- **Contabo** дешевий, але CPU перепідписаний: піки обробки фото будуть
  повільнішими, ніж на OVH/Hetzner.
- **Українські ДЦ** мають генератори, але блекаути впливають на канали
  зв'язку; для магазину це привід мати статус-сторінку/сповіщення.
- **Маленькі провайдери** (AlphaVPS, SVAI) — один ДЦ, менша команда; ціну
  переваги треба зважувати на критичності магазину.
- **Верифікація платежу**: OVH/Hetzner можуть попросити документи; краще
  зареєструвати акаунт заздалегідь, а не в день деплою.
- Міграція між провайдерами дешева: усе — Docker Compose + `pg_dump`, тому
  вибір не є незворотним.
