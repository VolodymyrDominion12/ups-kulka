# Дизайн вітрини

Основа для фронтенду на Next.js (специфікації 003-product-page, 004-checkout).
Кольори — з нинішнього сайту oops.kylka.shop (рішення власника: «кольори
зберегти, дизайн покращити»).

- `tokens.css` — CSS-змінні (кольори, шрифти, радіуси) для `app/globals.css`.
- `tailwind.theme.ts` — ті самі токени для `tailwind.config` (технічний план: Tailwind).
- `preview.html` — інтерактивне демо дизайну: каталог зі 211 товарів старого
  сайту, фільтри, кошик, оформлення. Відкривається у браузері без збірки.
  Фото товарів у демо замінено ілюстраціями; замовлення не надсилаються.
  Онлайн-демо: https://claude.ai/artifact/HyYb7HdBU6CBVK4dj6nADe

| Токен | Значення | Роль |

## Що змінено порівняно зі старим сайтом

- **Шрифти:** Comfortaa (округлий, як кульки) — логотип і заголовки; Manrope —
  текст. Обидва з кирилицею, через `next/font` з кириличним сабсетом.
- **Головний екран:** великий «Упс!» і «гроно» з фото композицій, вирізаних у
  форму кульок на ниточках, замість темного слайдера, де фото перекривало текст.
  Одна анімація при завантаженні, `prefers-reduced-motion` її вимикає.
- **Кнопки без ВЕЛИКИХ ЛІТЕР:** «Додати» замість «ДОДАТИ».
- **Каталог:** чипи категорій із кількістю товарів, окремий фільтр «Акції»;
  пошук і сортування закріплені під шапкою; кнопка «+» на картці стає лічильником.
- **Оформлення:** кошик збоку, форма в два кроки, екран «Дякуємо» з номером.
- **Доставка:** вибір «Самовивіз / Таксі». Біля таксі — пояснення, що поїздку
  клієнт оплачує окремо за тарифом таксі (рішення власника від 2026-11-03).
- **Оплата:** перемикач «При отриманні / Онлайн» показується, лише якщо
  `GET /api/v1/orders/checkout-options` повертає `online`.
- **Мобільне:** нижня панель кошика, кнопки 44 px, сітка 2 в ряд.

## Як це лягає на технічний план

- Публічні сторінки (головна, підбірки, товар) — Server Components, дані з API.
- Інтерактивне (кошик, фільтри, оформлення) — Client Components; ціну на клієнті
  лише показуємо, рахує її сервер.
- Тексти, структура сторінки і поведінка — з `preview.html`; React-компоненти
  переносяться в Feature-Sliced Design (`widgets/hero`, `features/cart`,
  `features/checkout`, `entities/product`).
