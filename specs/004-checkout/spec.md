# 004 — Оформлення замовлення

Статус: в роботі (бекенд). Рішення власника від 2026-11-03.

## Навіщо
Покупець має замовити кульки без дзвінка: обрати товари, спосіб отримання й
оплати та отримати номер замовлення. Магазин миттєво дізнається про замовлення.

## Рішення власника
- **Власних кур'єрів немає.** Доставка — таксі; покупець оплачує вартість
  поїздки за тарифом таксі окремо, у суму замовлення вона не входить.
- Самовивіз доступний завжди.
- Оплата: при отриманні або онлайн. Онлайн-оплата вмикається, лише коли задано
  ключі платіжного сервісу (специфікація 006); до того її не видно покупцю.
- Про нове замовлення власник отримує повідомлення в Telegram (специфікація 008).

## Сценарії
1. Покупець надсилає кошик (товар + кількість), ім'я, телефон, спосіб
   отримання (`pickup` або `taxi` з адресою), бажані дату й інтервал, коментар,
   спосіб оплати.
2. Сервер бере ціни з каталогу, рахує суму і зберігає замовлення з номером.
3. Якщо обрано онлайн-оплату — у відповіді є посилання на сторінку оплати.
4. Вітрина запитує доступні способи отримання й оплати, щоб показати лише їх.

## Критерії приймання
- Ціни й назви беруться лише з каталогу на момент замовлення; клієнт ціну не
  передає. Неактивний або неіснуючий товар → 422 `product_unavailable`.
- Телефон приймається як `093 111 22 33`, `0931112233`, `+380931112233`,
  зберігається як `+380XXXXXXXXX`; інакше → 422 `invalid_phone`.
- `taxi` без адреси → 422 `address_required`.
- Порожній кошик → 422; кількість одного товару 1–99; до 50 позицій.
- Однакові товари в кошику зливаються в одну позицію.
- Онлайн-оплата без ключів → 422 `online_payment_unavailable`.
- Номер замовлення — зростаюче ціле число для людей (з 1001).
- Помилка відправки в Telegram або створення платежу не втрачає замовлення.
